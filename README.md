# writing-skills

Claude skills for writing tasks. Each skill lives in its own folder with a `SKILL.md`, developed on its own branch.

| Skill | Branch | Purpose |
|-------|--------|---------|
| one-pager | `one-pager` | One-page project introduction for proposals, outreach, and briefs |
| argument-tree | `argument-tree` | Grayscale PDF argument tree: thesis -> claims -> tagged theoretical, literature and numerical evidence with caveats |
